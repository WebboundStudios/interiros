# AI Development Rules

## General

Never generate placeholder-looking websites.

Everything should feel handcrafted.

Never copy another website.

Use inspiration only.

---

## Code

Use functional React components.

Use TypeScript.

Use hooks correctly.

Avoid unnecessary state.

Prefer composition over duplication.

Keep components small.

Never write spaghetti code.

---

## Styling

Tailwind only.

No inline styles.

No CSS files unless absolutely required.

Responsive first.

Desktop should not be the only target.

---

## Animations

Use GSAP for scroll animations.

Use Framer Motion for component transitions.

Use Lenis for smooth scrolling.

Animations must enhance UX.

Never animate everything.

Luxury = subtle.

---

## Performance

Lazy load images.

Avoid unnecessary rerenders.

Memoize expensive calculations.

Use React.memo only when useful.

Optimize bundle size.

---

## Accessibility

Semantic HTML.

Keyboard navigation.

ARIA labels.

Proper heading hierarchy.

Color contrast.

---

## Do NOT

Do not copy Dekora Studio.

Do not use lorem ipsum.

Do not use random stock images.

Do not overuse gradients.

Do not overuse glassmorphism.

Do not generate generic agency layouts.
